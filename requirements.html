Event Requirements

What you need to include in your website

Your submission must include:

  • HTML Features (at least 5): Semantic HTML5 elements, forms, tables, multimedia elements, and proper document structure.
  • CSS Features (at least 5): Responsive design, animations, transitions, custom properties (variables), and flexbox or grid layouts.
  • JavaScript Functions (at least 4): Interactive elements, form validation, DOM manipulation, and event handling.
  • Waffle Theme: Incorporating a waffle theme is encouraged but optional.
  • Responsive Design: Your website must look good on all devices (desktop, tablet, and mobile).
  • Cross-Browser Compatibility: Your website must work in modern browsers (Chrome, Firefox, Safari, Edge).
  • Performance: Your website must load quickly and efficiently.
  • Accessibility: Your website must be accessible to all users, including those with disabilities.

Technical Requirements Breakdown

HTML (5+ features)

  • Semantic HTML5 elements (header, footer, nav, section, article, etc.)
  • Forms with various input types
  • Tables for structured data
  • Multimedia elements (images, audio, video)
  • Proper document structure and metadata
  • SVG graphics
  • Lists (ordered, unordered, definition)

CSS (5+ features)

  • Responsive design with media queries
  • Animations and transitions
  • Custom properties (CSS variables)
  • Flexbox or Grid layouts
  • Pseudo-classes and pseudo-elements
  • Transforms (2D or 3D)
  • Advanced selectors
  • Custom fonts

JavaScript (4+ functions)

  • Form validation
  • DOM manipulation
  • Event handling
  • Interactive elements
  • Local storage usage
  • Fetch API or AJAX
  • Animation control
