# Waffles Event Website

A creative and interactive website for the Waffles Event competition, where participants can submit their waffle-themed websites to win prizes.

## Features

### HTML Features
- Semantic HTML5 structure with header, footer, nav, section elements
- Responsive navigation menu with mobile toggle
- Form with validation in the Get Started page
- Image gallery with captions
- Organized content sections with proper hierarchy

### CSS Features
- Custom CSS variables for consistent theming
- Responsive design using media queries
- CSS animations and transitions
- Flexbox and Grid layouts
- Pseudo-elements and pseudo-classes for enhanced styling
- Hover effects and interactive elements
- Custom waffle-themed background patterns

### JavaScript Features
- Random waffle fact generator that changes periodically
- Mobile navigation menu toggle
- Form validation with error handling
- Active page highlighting in navigation
- Page transition effects

## Pages

1. **Home** - Introduction to the event with a call to action
2. **Gallery** - Showcase of previous waffle-themed websites
3. **Requirements** - Technical requirements for submissions
4. **Rules** - Guidelines and rules for participation
5. **Prizes** - Information about what participants can win
6. **Get Started** - Registration form and resources
