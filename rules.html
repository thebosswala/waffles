Event Rules

Guidelines for participating in the Waffles Event

  • Eligibility: Open to all web developers, designers, and enthusiasts of all skill levels.
  • Original Work: All submissions must be original work created specifically for this event.
  • Submission Deadline: All entries must be submitted by August 24, 2025 at 11:59 PM PST.
  • Theme Compliance: Incorporating a waffle theme is encouraged but optional.
  • Technical Requirements: All websites must meet the minimum technical requirements outlined in the Requirements section.
  • Code Quality: Code should be well-organized, commented, and follow best practices.
  • Plagiarism: Plagiarism will result in immediate disqualification. You may use open-source libraries and frameworks, but the design and implementation must be your own.
  • Submission Format: Submissions should include a link to the live website and a GitHub repository containing all source code.
  • Judging Criteria: Entries will be judged on creativity, technical implementation, visual design, user experience, and theme integration.
  • One Entry Per Person: Each participant may submit only one entry.
  • Feedback: All participants will receive feedback on their submissions from our panel of judges.
  • Amendments: The organizers reserve the right to amend these rules at any time. Any changes will be communicated to all participants.

Important Note

By submitting an entry, you grant the Waffles Event organizers the right to showcase your work on our website and social media channels. You retain all other rights to your work.

If you have any questions about the rules, please contact us at info@wafflesevent.com.
